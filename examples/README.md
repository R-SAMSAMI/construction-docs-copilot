# Example Demo Cases

These examples make the repo easier to demo even before live API credits are used.

## Suggested Images To Use

Look for publicly shareable or personal non-confidential images that include:

- scaffold or ladder work
- active excavation or trenching
- material staging and housekeeping issues
- workers near mobile equipment
- roof or edge work

## How To Use These Examples

1. Start the app in Demo Mode
2. Upload a construction image
3. Copy one of the example contexts below into the form
4. Walk through the generated output as if you are demoing the product to a hiring manager

## Example Context 1

- Project type: Bridge rehabilitation
- Work activity: Scaffold inspection and concrete patch repair
- Notes: Crew working adjacent to traffic. Access routes are tight and temporary materials are staged near the work area.

## Example Context 2

- Project type: Commercial building shell
- Work activity: Steel erection and decking support
- Notes: Multiple crews are active. Crane picks are occurring nearby and coordination between trades is important.

## Example Context 3

- Project type: Residential framing
- Work activity: Roofing and exterior edge work
- Notes: Work is elevated and housekeeping around access ladders should be checked before the shift continues.
